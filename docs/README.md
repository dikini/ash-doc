# Project documentation

This directory contains ash-doc project policy and active planning records. It
does not contain published Ash instruction or define Ash behavior.

- [Project workflow](project/workflow.md) defines how a reader question becomes
  a complete, verified documentation unit.
- [Beginning learning path](project/beginning-learning-path.md) connects the
  provisional reader questions that shape the early learning sequence.
- [Roadmap](project/roadmap.md) records the next complete project increment and
  the work it depends on.
- [Plans](plans/README.md) contains temporary design and execution records owned
  by an active roadmap outcome or bounded repository decision.

Published learning material belongs under [`content/`](../content/README.md).
Executable experiments belong under [`lab/`](../lab/README.md). Source and
technique evaluations belong under [`research/`](../research/README.md).
