# Функциите като стойности {#functions-as-values}

В урока за няколко входа частичното извикване `add 20` произведе функция.
Тази функция можеше да изчака още едно цяло число, защото функциите са
стойности в Ash. Подобно на другите стойности, функция може да се подаде като
вход, да се получи като резултат и да се свърже с име.

Така една функция може да описва *кога* да се използва друго изчисление. Ще
започнем с функция с име, после ще премахнем името и накрая ще създадем
функция, която помни по-ранен вход.

## Подаване на функция като вход {#giving-a-function-as-an-input}

Да предположим, че искаме да приложим едно и също преобразуване на цяло число
два пъти:

<!-- source: src/01-named-function.ash -->
```ash
increment : Int -> Int
increment number = number + 1

apply_twice : (Int -> Int) -> Int -> Int
apply_twice transform number = transform (transform number)

main : Unit -> Int
main () = apply_twice increment 40
```

Първият вход на `apply_twice` е от тип `Int -> Int`. Скобите в
`(Int -> Int) -> Int -> Int` държат целия тип на функцията заедно. След като
получи такава функция, `apply_twice` получава цяло число и произвежда цяло
число.

В тялото `transform` означава функцията, подадена при извикването. Предскажете
стойността след първото и след второто ѝ прилагане. Стартирайте програмата;
Ash отчита `42 : Int`. Заместването с подадената функция обяснява двете
извиквания:

```text
apply_twice increment 40
increment (increment 40)
increment 41
42
```

Не е нужен специален синтаксис за извикване на параметъра функция;
`transform number` работи като всяко извикване на функция с име, което сме
писали досега. Функция, която получава друга функция, като `apply_twice`, се
нарича *функция от по-висок ред*.

## Писане на функция там, където е нужна {#writing-a-function-where-it-is-needed}

Ако една малка функция се използва само на едно място, отделната дефиниция
може да прикрие изчислението, вместо да го изясни. *Анонимната функция* е
израз на функция без име на ниво изходен код:

<!-- source: src/02-anonymous-function.ash -->
```ash
apply_twice : (Int -> Int) -> Int -> Int
apply_twice transform number = transform (transform number)

main : Unit -> Int
main () = apply_twice (fn(number) {
    number + 1
}) 40
```

Прочетете израза в скобите като „функция от `number` с резултат
`number + 1`.“ Ash знае, че `apply_twice` изисква `Int -> Int`, затова
параметърът и резултатът се проверяват като цели числа.

Предскажете дали замяната на функцията с име променя някое от двете
прилагания. Повторното стартиране дава `42 : Int`: анонимното тяло прибавя
единица при всяко извикване. Изборът между функция с име и анонимна функция е
свързан с обяснението: дайте име на функция, когато то помага на читателя или
изчислението се използва повторно; оставете краткото локално преобразуване до
мястото, където се използва, когато така е по-ясно.

## Произвеждане на функция {#producing-a-function}

Изразът на функция може да използва параметър от заобикалящата дефиниция. Този
параметър остава достъпен и след като извикването на заобикалящата функция е
произвело новата функция:

<!-- source: src/03-remembered-input.ash -->
```ash
make_adder : Int -> Int -> Int
make_adder amount = fn(number) {
    amount + number
}

main : Unit -> Int
main () = make_adder 20 22
```

`make_adder` първо получава `amount`. Резултатът му е анонимната функция
`fn(number) { amount + number }`. Тази функция помни конкретния `amount` от
извикването, което я е създало; стойност на функция, която носи свързванията
от мястото на създаването си, се нарича *затваряне*.

Кой вход се запазва при създаването на функцията и кой пристига при
извикването ѝ? Предскажете крайната стойност, преди да стартирате. Ash отчита
`42 : Int`. Първо проследете създаването:

```text
make_adder 20
fn(number) { 20 + number }
```

Подаването на оставащия вход продължава изчислението:

```text
make_adder 20 22
20 + 22
42
```

Създаването на анонимната функция запазва `20`, без да извършва
събирането. По-късното извикване подава `22`, след което тялото изчислява
резултата. Това е предишната идея за частично извикване, записана подробно:
създаването произвежда `Int -> Int`, а извикването му произвежда цяло число.

## Параметърът функция изисква функция {#a-function-parameter-requires-a-function}

Типовете функции запазват същата граница като другите типове. Първият вход на
`apply_twice` не може да бъде цяло число:

<!-- source: src/04-not-a-function.ash -->
```ash
apply_twice : (Int -> Int) -> Int -> Int
apply_twice transform number = transform (transform number)

main : Unit -> Int
main () = apply_twice 2 40
```

Сравнете типа на първия аргумент с договора за вход в скобите. Коя стойност
трябва да може да бъде извикана? Стартирайте тази версия от `content/learn`:

## Упражнение: прилагане три пъти {#exercise-apply-three-times}

Започнете с ново копие на `src/01-named-function.ash` в работната си
директория, като запазите `increment`.

Дефинирайте повторение, което прави още една стъпка:

```text
apply_three_times : (Int -> Int) -> Int -> Int
```

Тялото му прилага `transform` три пъти, като резултатът от всяко извикване
подава към следващото. Първо го стартирайте с функцията с име `increment` и
стойността `39`; после заменете `increment` с анонимна функция, която
прибавя единица. Проследете и двете програми, преди да ги стартирате — те
трябва да произведат едно и също цяло число и да извършат три извиквания на
подадената функция.

## Изчисленията като данни {#calculations-as-data}

Стойността на функция носи изчисление, което може да се използва по-късно.
Функция може да получи такава стойност, да я извика или да върне нова функция.
Анонимната функция описва изчислението в израза, където е нужна, и може да
помни имена от заобикалящия я израз.

`apply_twice` работи само с функции от `Int` до `Int`, макар че
структурата му не зависи от цели числа. По подобен начин и нашият `IntList`
повтаря форма, която не е необходимо да се ограничава до елементи цели числа.
Следващият урок разглежда как една дефиниция може да изрази тази независимост
от конкретен тип.
