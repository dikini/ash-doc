# Накъде продължава Ash {#where-ash-goes-next}

Един модел съпътстваше този път от първия до последния изходен файл:
дефинициите описват изрази, а изразите изчисляват стойности. Програмите
нараснаха от един израз до рекурсивни данни, граници между модули и текст, а
моделът остана същият през всички уроци.

Ash има възможности, които не бяха нужни по този път, и три от тях си струва
да разгледате, преди да го напуснете. Всяка разширява модела, вместо да го
заменя, и всяка принадлежи на път, който продължава след този. Този
заключителен урок показва и трите в действие с малки програми, които можете да
стартирате. Не е нужно да научавате механизма на нито една от тях; нужно е да
разпознаете формата и да последвате препратката към пътя, който ги развива.

## Поведение, зададено от дефиниция {#behavior-a-definition-states}

[Дефинициите за много типове](../definitions-for-many-types/README.md)
завършиха с обещание. Параметричният полиморфизъм задава една дефиниция за
всеки тип; другата основна форма, *ad-hoc полиморфизмът*, дава на една
операция различни реализации за различните типове. Ash предоставя тази форма
чрез интерфейси, а `01-twice.ash` показва целия механизъм наведнъж:

<!-- source: src/01-twice.ash -->
```ash
interface Twice<A> {
    double : A -> (A, A)
}

impl Twice<Int> {
    double value = (value, value)
}

replicate : A -> (A, A) where Twice<A>
replicate item = double item

main : Unit -> (Int, Int)
main () = replicate 21
```

`Twice<A>` назовава възможност: за даден тип `A` една стойност може да
бъде удвоена до двойка. Реализацията предоставя тази възможност за `Int`.
Сигнатурата на `replicate` отбелязва нуждата ѝ чрез `where Twice<A>`, а тялото
ѝ извиква `double` като обикновена функция. Когато `main` извика
`replicate 21`, проверката задава `A` като `Int`, а реализацията за
`Int` дава отговора. Това са [формите за интерфейс и
реализация][forms], които проверяващият проверява.

Предскажете показаната двойка, преди да стартирате програмата. От директорията
`src` на този урок:

```text
$ ash 01-twice.ash
(21, 21) : (Int, Int)
```

Нуждата беше посочена в сигнатурата и удовлетворена, без поведението да се
подава като аргумент. [Пътят за библиотеките](../../libraries/README.md)
развива интерфейсите и доказателствата за техните реализации, като започва от
тази форма в [избора на доказателство за
реализация](../../libraries/choosing-implementation-evidence/README.md).

## Стойност, предоставена от обработвач {#a-value-a-handler-supplies}

Понякога едно изчисление има нужда от стойност, която не бива да избира само.
Един *ефект* заявява заявката, а обкръжаващият го *обработвач* отговаря на
нея. `02-scale-price.ash` заявява множителя за цена:

<!-- source: src/02-scale-price.ash -->
```ash
effect Scale {
    by : Int -> Int
}

price : Int -> Int ! {Scale}
price base = perform Scale.by base

main : Unit -> Int
main () = handle (price 20) with Scale {
    by factor => resume (factor * 3)
}
```

Декларацията `effect Scale` назовава една операция, `by : Int -> Int`. Вътре в
`price` `perform Scale.by base` прави заявката, а `! {Scale}` в сигнатурата
отбелязва оставащата нужда като част от договора на изчислението. [Правилата
за ефекти][effects] и [записът на редовете][rows] описват двете части.
Клонът на обработвача свързва заявеното цяло число с `factor` и отговаря с
`resume (factor * 3)`, което предоставя стойността и продължава изчакващото
изчисление.

Проследете заявката и пресметнете умножението, преди да стартирате програмата;
отново го направете от директорията `src` на този урок:

```text
$ ash 02-scale-price.ash
60 : Int
```

`price` никога не избира множител; това прави обработвачът. [Пътят за
ефектите](../../effects/README.md) развива началната си глава [Заявка за
стойност](../../effects/requesting-a-value/README.md) около този обмен.

## Клетка, притежавана от обхват {#a-cell-a-scope-owns}

Третата възможност дава на един обхват притежавано място, в което да държи
цяло число, докато трае изчислението. `03-cell-tally.ash` придобива такава
клетка, заменя съдържанието ѝ и го прочита:

<!-- source: src/03-cell-tally.ash -->
```ash
import @builtin.cell as Cell

main : Unit -> Int
main () = resource cell<R> tally = 0 {
    let ignored = Cell.write (tally, 7)
    Cell.read tally
}
```

`import @builtin.cell as Cell` прави операциите с клетка, притежавани от
компилатора, достъпни под псевдонима `Cell`. Формата
`resource cell<R> tally = 0 { ... }` придобива клетка, съдържаща `0`, и
изпълнява тялото си, като `tally` назовава клетката; обхватът притежава
освобождаването ѝ, когато тялото приключи. `Cell.write` заменя цялото число в
клетката, а `Cell.read` копира текущото число навън. [Правилата за
клетките][cells] описват придобиването и обхвата, който притежава клетката.

Предскажете копираното цяло число, след което стартирайте програмата от
директорията `src` на този урок:

```text
$ ash 03-cell-tally.ash
7 : Int
```

Записът замени началното `0`, преди да се извърши прочитането, затова
тялото връща `7`. Пътят за ефектите развива клетките с ограничен обхват
след главите за обработвачи в [Броене с
клетка](../../effects/counting-with-a-cell/README.md).

## Упражнение: изберете друг отговор {#practice-choose-a-different-answer}

Направете ново копие на `02-scale-price.ash` в работна директория извън
дървото на `src` на този урок и стартирайте копието оттам. Променете клона
на обработвача така, че да отговаря със заявения множител плюс десет, вместо с
множителя по три. Предскажете резултата на програмата, преди да стартирате
копието, след което посочете кой ред избира отговора и кой ред само го
заявява.

Нищо в тези програми не нарушава модела на пътя. Интерфейсът посочва нужда в
сигнатура; ефектът посочва нужда в ред; обхватът на ресурс притежава клетка,
докато изразите изчисляват стойности в нея. Трите възможности разширяват
модела, вместо да го заменят, а [пътят за
библиотеките](../../libraries/README.md) и [пътят за
ефектите](../../effects/README.md) ги развиват подред, като всеки надгражда
дефинициите, сигнатурите и изпълненията от този път.

Успех по пътищата нататък и предсказвайте, преди да стартирате.
