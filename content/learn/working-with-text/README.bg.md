# Работа с текст

Досега всеки резултат беше цяло число, булева стойност или кортеж, съставен от
тях. Програма, която поздравява потребителя си, подписва съобщение или
отговаря с дума, работи с текст. Текстът също е стойност в Ash. Той има
собствен тип, `String`, а `ash` го показва заедно с типа му, както
показваше и `42 : Int`.

## Първи текст

Стрингов литерал е текст, записан между двойни кавички:

<!-- source: src/01-greeting.ash -->
```ash
main : Unit -> String
main () = "Hello, Ash!"
```

Предскажете какво ще покаже `ash` за тази програма, после я стартирайте:

```text
"Hello, Ash!" : String
```

При показването стойността е в кавички, а типът ѝ след двоеточието. Кавичките
отбелязват къде текстът започва и свършва; низът е текстът между тях, съхранен
като една стойност.

## Нов ред в кавичките

Някои знаци не могат да се въвеждат директно между кавичките. Екраниращата
последователност `\n` означава нов ред, така че един низ може да съдържа
два реда:

<!-- source: src/02-escapes.ash -->
```ash
main : Unit -> String
main () = "line one\nline two"
```

Предскажете показаната стойност, преди да стартирате програмата:

```text
"line one\nline two" : String
```

Стойността не се разделя на два изходни реда. При показването екраниращата
последователност `\n` се повтаря, за да остане резултатът четим като един
низ. Ash допуска шест екраниращи последователности: `\"` и `\\`
записват кавичка и обратна наклонена черта, `\n` и `\r` записват
нови редове, `\t` записва табулация, а `\0` записва NUL. Те са
изброени в главата [Лексикална структура][lexical].

## Измерване на текст

Колко текст съдържа един низ? Модулът `@builtin.string` предоставя
[операциите, дефинирани за низове][builtin]. Той принадлежи към `@builtin`
корена, който назовава модулите, включени в компилатора, затова този импорт не
изисква наш собствен файл:

<!-- source: src/03-byte-length.ash -->
```ash
import @builtin.string as Text

main : Unit -> Int
main () = Text.byte_length "a\nb"
```

Псевдонимът `Text` дава кратки квалифицирани имена на операциите.
`Text.byte_length` отчита колко байта заема текстът в низа. Пребройте ги тук:
една буква, един нов ред, записан като екранираща последователност, и още една
буква. Предскажете цялото число, преди да стартирате програмата:

```text
3 : Int
```

Екраниращата последователност `\n` се брои веднъж, като един знак от
текста.

## Текстът като байтове

Низът е текст. Програма, която съхранява текст или го изпраща нататък, работи
с байтовете му, а `Text.to_utf8` преобразува низа в тези байтове:

<!-- source: src/04-to-utf8.ash -->
```ash
import @builtin.string as Text

main : Unit -> Bytes
main () = Text.to_utf8 "a\nb"
```

Предскажете типа на резултата и колко числа ще съдържа показването му, после
стартирайте програмата:

```text
[97, 10, 98] : Bytes
```

Типът на резултата е `Bytes` и той се показва като списък от числа, по едно
за всеки байт. Появяват се три числа — същите три, които отчете `byte_length`.
Така измерването на низа и преобразуването му описват текста по един и същи
начин. Средното число показва къде се намира новият ред.

## Равенството остава при целите числа

Урокът за избор на резултат попита дали две цели числа са равни чрез
`==`. Съвсем естествено е да зададем същия въпрос за два низа.
Предскажете дали `ash` ще приеме тази програма, после я стартирайте от
`content/learn`, за да сравните с пълното съобщение:

<!-- source: src/05-string-equality.ash -->
```ash
main : Unit -> Bool
main () = "a" == "a"
```

`ash` отказва програмата, преди да я стартира:

<!-- markdownlint-disable MD013 -->
```text
$ ash --message-format human --locale en working-with-text/src/05-string-equality.ash

  --> /path/to/ash-doc/content/learn/working-with-text/src/05-string-equality.ash:2:11
2 | main () = "a" == "a"
  |           ^ This has type `String`.
  --> /path/to/ash-doc/content/learn/working-with-text/src/05-string-equality.ash:2:15
2 | main () = "a" == "a"
  |               ^ This operator requires `Int` operands.
reason: type.operator-operand
```
<!-- markdownlint-enable MD013 -->

Първият етикет сочи левия операнд и отчита типа му, `String`. Вторият етикет
сочи самия оператор и повтаря изискването му: операнди от тип `Int`.
[Правилата за операторите][primitive] фиксират типовете на тези операнди и
важат и за събирането: в това издание `+` и `==` съчетават и
сравняват само цели числа, затова няма оператор, който да обединява два низа.
Модулът за низове предлага сравнение чрез име — `Text.equal` приема двата низа
като една двойка — но на това ниво текстът се измерва и преобразува, а не се
обединява.

## Упражнение: поздрав на два реда

Започнете с ново копие на `src/03-byte-length.ash` във вашата работна
директория.

Етикетът с името съдържа два реда — `Hello,` на първия и `Ada` на втория
— записани с един стрингов литерал. Променете програмата така, че `main` да
показва този низ, после предскажете и проверете още две неща: колко байта
отчита `Text.byte_length` за поздрава и кое число в показването на
`Text.to_utf8` съдържа новия ред.

## Текст сред стойностите

Текстът се държи като стойностите, които вече познавате: показва се заедно с
типа си, а екраниращите последователности записват знаците, които клавиатурата
не може да въведе. Модулът `@builtin.string` измерва текста и го преобразува в
байтове. В това издание няма оператор, който да обединява низове; `+` и
`==` остават за целите числа.

Низът е подходящ за текст, записан там, където се използва. Програма се нуждае
и от данни, чиито имена показват какво означава дадена стойност и какви форми
може да приема; следващият урок дефинира такива данни.
